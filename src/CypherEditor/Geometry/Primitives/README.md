# Primitives

## Owns

Deterministic parameter records and generators for planes, boxes, wedges, prisms, pyramids, cylinders, cones, spheres, arches, and stairs.

## Does not own

Thousands of hard-coded shape algorithms; large libraries of shapes are data-driven templates built from tested generators.

## First acceptance gate

Generate canonical brush-first box, wedge, arch, and stair fixtures at valid and rejected parameter boundaries.
