CypherEngine Changelog
======================

All notable changes to CypherEngine and the REAP game/runtime direction are tracked here.

[Unreleased] - 2026-10-14
-------------------------

Changed
- The projected World shadow regression uses an explicit value-initialized
  pipeline descriptor for its HDR tone-map pass. This fixes the shared GCC
  build error in Ubuntu Debug, Release and ASan/UBSan CI; the native OpenGL
  smoke suite passes locally after the change.
- The combined cooked World regression runs a generated D24 shadow pass,
  an RGBA16F camera pass and fixed Reinhard tone mapping to an RGBA8 target.
  A separate light submission retains an off-camera caster, with the same
  nonidentity light matrix for caster and receiver. Native pixels verify
  direct-light shadowing, retained UV1 baked light, radiance above 1.0 and a
  moving shadow after updating only the caster's light submission and aligned
  Model batch. Material-bridge, World-draw and native OpenGL 4.1 smoke suites
  pass locally. This is a hand-built cooked shader integration fixture;
  authored lights, general pass scheduling and a map-loaded runtime scene
  remain separate work.
- Cooked material bundle creation rejects an output that still owns shader,
  pipeline, texture or material-uniform handles. Repeated creation returns
  INVALID_ARGUMENT before resource reads or output changes, keeping the
  original draw bindings usable and destructible once. Focused material-
  bridge tests cover textured and tint-uniform bundles.
- OpenGL capability queries report only public renderer features:
  rasterization, indexed instancing, float render targets, supported sRGB
  presentation and default-framebuffer multisampling. Indirect draws,
  geometry/tessellation stages, texture arrays, GPU timestamps, anisotropy and
  compressed uploads keep reserved bits clear even when the driver supports
  them. Requiring one of those bits fails initialization with
  ERR_CAPABILITY_MISSING. The default optional-capability mask is empty;
  OpenGL does not use it to enable features. Focused runtime and native
  OpenGL 4.1 smoke tests pass locally. Offscreen multisampling and the
  reserved feature paths remain unimplemented.

Added
- cypher_render_world_lighting runs the public camera/shadow World adapters
  with a procedural floor, two rotating boxes (one mirrored/nonuniform),
  a shadowed directional light, an unshadowed point light and HDR tone-map
  presentation. Independent view submissions and aligned Model112/Model64
  batches feed its passes. Native hidden/visible finite runs pass; a 120-frame
  resize check completes 360 camera and 360 shadow draws, 120 presentations
  and two HDR target replacements. Explicit owners release shared material
  resources once; pending target allocations and retained uniform staging
  are cleaned up on shutdown. World-draw, material-bridge and native pixel
  suites pass locally. CI builds the example and uses the offline shader
  cooker. Local packaging used the existing cooked-format writer; removed
  shader-tool SDK dependencies were not restored. Host-defined materials and
  lights are limited to this sample; map/material loading, lightmap baking,
  general frame scheduling and Mason wiring remain separate work.
- An opaque cooked World material combines UV0 albedo, a supplied UV1
  lightmap and a UV0 normal map with a caller-owned D24 comparison shadow map
  in sampled slot 3. Creation validates all four shader bindings and owns
  only the three material textures. Draw preparation validates and preserves
  the live depth texture and comparison sampler; invalid bindings leave the
  draw unchanged. Material-bridge, World-draw and native OpenGL 4.1 smoke
  suites pass locally; the new pixel test includes a shadowed camera draw
  that retains baked light.
  The host still owns the shadow pass and lighting equation; the fixture
  uses hand-built cooked shader data, not an authored shader or lightmap baker.
- Opaque cooked World materials can bind COLOR albedo on UV0, a supplied
  linear lightmap on UV1, and a linear RGBA8 tangent-space normal map on UV0
  in one three-texture draw. The bridge checks both vertex attributes, UV
  sets, texture roles and formats before GPU creation, and retires partial
  ownership if the third upload fails. Focused CPU tests and a native OpenGL
  4.1 World camera pixel test vary normal and lightmap independently with
  constant albedo. The shader fixture is hand-built cooked data; authored
  shader recipes, lightmap baking and directional lightmaps remain separate
  work.
- Graphics pipelines and indexed draws support up to four sampled textures,
  subject to the device texture-unit limit. Hosted OpenGL 4.1 rendering
  preserves host texture and sampler bindings on units 0-3. Focused CPU
  draw/texture tests and a native hosted four-sampler pixel/state test pass
  locally. The optional cooked-material pass shadow uses slot 1 for albedo
  alone or slot 3 for the combined albedo/lightmap/normal recipe.
- Cooked linear RGBA8 normal textures can upload, and opaque cooked World
  materials may bind one beside COLOR albedo on UV0. The bridge requires a
  tangent vec4 at vertex location 4; wrong usage, format, UV, alpha state or
  layout fails before GPU creation, and upload failure rolls back. Focused
  texture/material CPU tests and a native OpenGL 4.1 World camera pixel test
  pass locally. Fixed albedo with opposite tangent-space normal texels changes
  directional diffuse, including after a mirrored World transform. This uses
  a hand-built cooked shader; a normal map in slot 1 cannot accompany the
  optional pass shadow in that slot.
- Opaque cooked World materials can adopt a second linear RGB lightmap on
  UV1 while albedo stays on UV0. The bridge requires RG32_FLOAT UV1 at vertex
  location 3; unsupported UV layouts, transforms and sRGB lightmaps fail
  before GPU creation, and a failed second upload rolls back. Focused CPU
  tests and a native OpenGL 4.1 World camera pixel test pass locally: fixed
  UV0 with varying UV1 produces bright and dim pixels. This accepts supplied
  lightmaps only. Baking, directional lightmaps, authored shader recipes and
  simultaneous pass shadows remain outside the cooked-material subset.
- World lighting has an opt-in 320-byte std140 View record: the existing
  256-byte ambient/directional/two-point layout stays intact, followed by a
  caller-supplied light clip-from-world matrix. The packer rejects nonfinite
  matrices and invalid lights without changing output. A native OpenGL 4.1
  pixel test joins World-prepared D24 caster and camera receiver draws through
  the cooked material's borrowed comparison shadow map while retaining the
  ambient, directional and point-light checks. CPU and native tests pass
  locally. The host still supplies lights, shadow target, View upload and
  pass order; authored shader recipes cannot emit the needed uniform-block
  or depth-sampler bindings. The supplied static-lightmap path above does
  not bake lighting.
- Cooked material bundles can reserve sampled slot 1 for a caller-owned D24
  shadow map and explicit comparison sampler while owning one albedo texture
  in slot 0. The bridge validates the cooked binding, draw-time resource pair
  and pipeline kind; World camera preparation preserves that pair after
  preflight, including mixed submissions with ordinary materials. Focused CPU
  tests cover ownership, rollback and failure atomicity; the native OpenGL
  smoke test exercises the binding with a shadowed pixel. This bounded path
  needs a hand-built cooked shader: the authored cooker cannot emit depth
  samplers, and World lighting still lacks a light-space matrix and pass
  schedule for a complete shadowed scene.
- A caller can pack a 256-byte std140 View lighting record for World camera
  draws, with camera matrices, ambient and directional radiance, and up to two
  point lights. R_PackWorldViewLighting validates inputs, normalizes the direction,
  zeroes inactive slots and leaves output unchanged on failure. Focused CPU
  tests verify layout and failure atomicity; a native OpenGL 4.1 pixel test
  combines View with the 112-byte normal-aware Model and a cooked tint material
  and checks ambient, directional, in-range, out-of-range and two-point light.
  The host supplies lights and uploads View; authored shader recipes cannot
  yet emit these uniform-block bindings. Mason live lighting and shadow
  sampling remain separate work.
- Cooked tint materials accept the World camera adapter's 80-byte
  MODEL_CUTOUT and 128-byte MODEL_NORMAL_CUTOUT std140 blocks alongside the
  existing 64/112-byte layouts. Mismatched cooked shader bindings and
  unsupported sizes still fail before GPU creation. Material-bridge CPU and
  native OpenGL 4.1 tests pass for both cutout layouts, including cooked alpha
  discard and tint. Authored shader recipes do not yet emit these uniform-
  block bindings, and Mason's live viewport remains separate work.
- World light-view shadow preparation now accepts opt-in MASK casters with
  dedicated depth-only pipelines. It packs a 64-byte Model record for opaque
  casters or an 80-byte record with the alpha cutoff for masked casters, binds
  the material's RGBA alpha texture at slot zero, and selects the mirrored
  variant for reversed winding. Mixed batches are preflighted before one
  aligned upload; invalid cutoffs, missing/stale alpha sources, wrong pipeline
  contracts, and casting BLEND/ADDITIVE materials leave output and batch
  unchanged. Focused World-draw and native OpenGL 4.1 tests pass locally; the
  native test confirms transparent texels leave a D24 light target clear while
  solid texels write depth. The shader still has to implement the documented
  discard, and authored uniform-block cooking and Mason's live viewport
  remain separate work.
- World camera and depth-writing preparation accept MASK materials with an
  opt-in 80-byte or 128-byte Model record carrying the cooked alpha cutoff;
  unmasked objects receive -1. Preflight requires a live scalar RGBA texture
  at slot zero and rejects invalid cutoffs before upload. MASK enters the
  opaque camera span. Focused World-draw tests cover packing, ordering and
  failure atomicity; a native OpenGL 4.1 pixel test verifies discarded and
  solid texels against a later depth-tested draw. Shader discard semantics,
  authored uniform-block cooking and Mason's live viewport remain future
  work.

[Unreleased] - 2026-10-13
-------------------------

Added
- World camera and opaque draws can opt into a 112-byte std140 Model record
  with model and inverse-transpose normal matrices. Invalid normal inverses
  fail before staging; the 64-byte default and shadow adapter remain available.
  Cooked tint materials accept either Model block size with tint in a separate
  uniform. Focused CPU and native OpenGL 4.1 pixel tests pass locally. General
  lighting, MASK/cutout World draws and editor integration remain separate work.
- World light-view shadow preparation filters a separate submission by
  cooked casts-shadows flags and prepares opaque depth draws, including
  reversed winding for mirrored models. It preflights depth-only pipeline
  state and model capacity, uploads one aligned batch and keeps public
  draws/count unchanged on validation or upload failure. Casting MASK,
  BLEND and ADDITIVE materials are rejected until cutout shadows have a
  contract. Focused World-draw and native OpenGL 4.1 smoke tests pass locally;
  the native test confirms an off-camera caster writes a D24 light target.
  The graybox sample still owns its larger shadow object block and schedule.
- World camera draw preparation now resolves a visible submission into
  opaque, far-to-near BLEND and ADDITIVE spans from cooked material bundles.
  It validates selected pipeline state and mirrored winding before one aligned
  model-uniform upload in final draw order. Invalid inputs leave public draws
  and counts unchanged; upload failure leaves a sealed batch for retry.
  Focused World-draw, scene-pass, material-bridge and native OpenGL 4.1 smoke
  tests pass locally, including transparent-order and depth-write pixels.
  Sort depth uses caller-maintained world AABBs and a matching camera view;
  intersecting translucent objects remain approximate. MASK and editor
  integration remain separate work.

Fixed
- World camera and opaque draw preflight rejects a color-write-disabled
  material pipeline before staging or publication. The material apply helper
  already checks selected winding; a focused regression covers it. Wireframe
  polygon mode remains available for intentional viewport previews.
  World-draw and native OpenGL 4.1 smoke tests pass locally.
- Opaque World draw preparation accepts finite, nonsingular mirrored
  transforms. Cooked material adoption owns a second, winding-reversed
  pipeline for every supported alpha mode while preserving culling, depth,
  blend and two-sided gl_FrontFacing behavior. Preflight selects that
  pipeline before staging; a missing variant leaves output and model uniforms
  untouched. Rollback and destruction retain retryable ownership of
  successfully created pipelines. A backend creation error followed by
  failure to destroy its returned native token remains a frontend cleanup
  limitation. Material-bridge, World-draw and native OpenGL 4.1 smoke
  tests pass locally, including pixels that distinguish culled, back-facing
  and front-facing mirrored geometry. Opaque World camera draws are covered;
  shadow and transparent World pass scheduling remain separate work.
- Opaque World draw preparation accepts valid small positive scales such as
  0.001 on each axis. Orientation uses binary64 without an unused inverse-
  matrix tolerance; singular transforms still fail before staging. At that
  milestone, World-draw tests passed 207 assertions in nine cases.
- Cooked-material preflight rejects incomplete authored mip chains before
  shader or texture GPU creation for RGBA8 and RGBA32_FLOAT. Material-bridge
  tests pass 807 assertions in seven cases.
- Mirrored graybox objects keep their outward faces under back-face culling.
  Normal packing reports validated transform handedness without changing its
  48-byte std140 layout; the sample chooses CW-front camera and shadow
  pipeline variants for a negative-X-scale cube, with variants for its other
  camera material modes. Invalid transforms leave both outputs unchanged.
  The normal test passes 23 assertions in three cases; native OpenGL smoke
  passes 1070 assertions including reversed-winding color/depth pixels; the
  120-frame hidden sample retains 840 scene, 600 shadow and 120 presentation
  draws. Pipeline selection is sample-owned, not a general instance policy.
- Borrowed OpenGL 4.1 frames capture and restore the host's alpha-to-coverage,
  alpha-to-one, sample-coverage and sample-mask enable bits. Renderer draws
  disable these inherited controls; numeric coverage and mask values remain
  untouched. The native host-surface smoke passes 239 assertions, checking
  state isolation without a multisampled pixel oracle.
- Standalone OpenGL 4.1 now follows the renderer's sRGB conversion setting,
  even if the default framebuffer is capable. BeginFrame reasserts it after
  external GL state changes. A native capable-but-disabled smoke case passed
  12 assertions; hosted-frame state restoration is unchanged.
- The tile-map preview fallback now cooks and stages a dedicated OpenGL 4.1
  shader matching its 208-byte Transforms block. Its default and both tile
  editor lookup paths no longer use the incompatible cube sample shader; the
  textured material reload path is unchanged. The installed resource compiler
  cooks and validates it without diagnostics. Runtime preview was not run
  because tile editor support is disabled in the compact build-mason tree.
- Uniform-batch append snapshots overlapping staging-source bytes before it
  clears alignment padding. A focused regression checks overlap, uploaded
  bytes, zeroed padding and unchanged state on capacity failure; the test passes.
- OpenGL draws disable inherited polygon line offset and line smoothing;
  hosted frames restore both. The hosted smoke seeds those states and checks
  both filled and wireframe draws plus restoration. Focused tests pass locally.
- The draw-queue test uses a renderer-specific result alias instead of global
  error_t, which collided with the Linux/POSIX typedef and broke Ubuntu Release
  CI compilation. Its focused test builds and passes locally; published CI
  validation follows this change.
- Public CypherWorld headers now explicitly qualify engine-wide Common and
  Math types, so they compile after headers declaring the separate
  cypher::engine::common namespace. The World test covers that include order.
- The macOS Mason CI smoke test now allows runner timing variance: a
  120-second cap failed after an earlier 118-second pass. Its focused CTest
  limit is 600 seconds and workflow limit is 300 seconds; the other 14 jobs in
  the preceding run passed.
- Buffer, vertex-input and graphics-pipeline creation now defensively destroy
  a native token returned with a backend creation error. Dependent shader and
  buffer references are released afterward. Three fake-backend failure tests
  and the focused draw test target pass; OpenGL already clears partial objects.

Added
- Graphics pipelines support three named uniform-buffer slots. Borrowed
  OpenGL 4.1 frames capture and restore all three indexed host bindings,
  offsets and sizes; frontend/backend contract versions are now 24/29.
  Hosted native smoke draws through slot 2 with a different host buffer
  there and verifies restoration. Draw tests pass 447 assertions in 22
  cases; hosted smoke passes 244 assertions in one case.
- The cooked-material bridge accepts one F32X4 tint under an explicit
  View/Model/Material std140 convention. It owns a 16-byte material uniform
  buffer, binds it per draw and carries it through World draw preparation.
  Failed rollback publishes live handles for retry. Other value layouts
  fail preflight before GPU creation. Material-bridge tests pass 1170
  assertions in ten cases; World-draw tests pass 233 assertions in ten cases;
  native OpenGL
  smoke passes 1402 assertions in two cases including a cooked HDR albedo
  and tint pixel oracle. Six focused CTests pass. Native shader reflection
  checks block size but not member names/offsets; checked-in source recipes
  cannot yet emit the required CYMT V2/CYSH V3 Material block.
- Cooked-material adoption accepts fully resident linear RGBA32_FLOAT 2D
  color textures with one level or complete authored mips alongside RGBA8.
  Float DATA images and streamed mip tails fail before GPU creation; existing
  cooked-texture validation and rollback handle exact bytes and failed
  uploads. Material-bridge tests pass 807 assertions in seven cases; native
  OpenGL 4.1 smoke passes 1342 assertions in two cases, including unclamped
  4.0 red sampled from cooked float albedo into an RGBA16F target. Fourteen
  focused World/render CTests pass. Cubemaps and streaming remain separate work.
- A separate CypherRenderWorldRuntime bridge prepares bounded opaque camera
  draws from an active, copied World submission. It resolves logical
  mesh/material slots through borrowed bundles, validates the visible set and
  uniform capacity before staging, uploads aligned model matrices once, and
  publishes ordered draws only after the upload succeeds. Stale tokens, bad
  slots, unsupported modes/transforms and capacity failure leave output
  unchanged; upload failure seals the caller's batch for retry or reset.
  The focused test passes 207 assertions in nine cases; a native OpenGL 4.1
  pixel oracle verifies a World model transform brings otherwise offscreen
  geometry into view through cooked material and static mesh bundles (1291
  smoke assertions in two cases). Six focused World/render CTests pass.
  Mirrored, shadow and transparent paths, authored meshes and general scene
  scheduling remain separate work.
- Immutable linear RGBA32F 2D textures upload directly or from fully
  resident cooked RGBA32_FLOAT color images, including complete authored
  mip chains. OpenGL 4.1 uses GL_RGBA32F/GL_FLOAT, isolates host pixel-unpack
  byte-swap and buffer state, and preserves values above 1.0 when sampled
  into an HDR target. Raw images may generate mips; float images are
  sampled-only, while RGBA16F remains the HDR target format. Public/backend
  contracts were versions 23/28 for that increment. Texture tests pass 781
  assertions in 26
  cases, native OpenGL smoke passes 1282 assertions including raw and mip
  pixels, and ten focused renderer CTests pass. The 120-frame hidden sample
  still renders its scene. Cooked-material RGBA32F adoption is recorded above;
  cubemaps and streaming remain future work.
- The graybox sample's fixed directional shadow averages a 3x3 neighborhood
  of nearest-filtered depth comparisons. Out-of-map taps count as lit, so
  the edge softens without darkening outside the light volume. A native
  pixel test compiles the checked-in shader and checks lit, shadowed and
  partial-edge colors with unchanged alpha. Shader validation/cooking has
  zero diagnostics; native OpenGL smoke passes 1216 assertions, ten focused
  renderer CTests pass, and the 120-frame hidden sample completes 840 scene,
  600 shadow and 120 presentation draws. The sample-only filter costs up to
  nine comparisons per covered fragment; cascades, authored lights and
  adjustable quality remain future work.
- R_ReadTargetRGBA32F reads RGBA16F offscreen color into caller-owned linear
  float pixels, preserving values above 1.0. Frontend validation covers
  frame/pass state, format, bounds, capacity and 16-byte row pitch; OpenGL
  restores the host read framebuffer, pixel-pack buffer and changed pack
  settings. Backend/public renderer contracts are versions 27/22. Native
  HDR readback sees a value of 4.0 before tone mapping, and ten focused
  renderer CTests pass. This synchronous path is for diagnostics, not live
  streaming capture.
- The OpenGL 4.1 graybox sample shades with two fixed, range-limited point
  lights alongside ambient and a shadowed directional light. A 320-byte
  std140 view record carries positions, ranges, linear colors, intensities
  and active count; the fragment shader adds unshadowed Lambert diffuse with
  quadratic range fade and preserves alpha cutout. Shader cooking has zero
  diagnostics; native OpenGL smoke passes 1176 assertions including count,
  range, color and unchanged-alpha pixels. The 120-frame hidden sample keeps
  840 scene, 600 shadow and 120 presentation draws. The native oracle now
  compiles the checked-in graybox stages and compares zero-, one- and two-
  light pixels. World-authored lights and point-light shadows remain future
  work.
- Scene classification has a separate, input-ordered ADDITIVE pass after
  opaque and far-to-near BLEND draws. It preflights the new output capacity
  and overlaps before writing indices. The graybox sample renders one
  depth-tested, non-depth-writing additive panel after its two translucent
  panels, using a bounded queue and cleaned-up pipeline. Scene-pass tests
  pass 719 assertions in six cases. A 120-frame hidden OpenGL run completes
  840 visible-object draws (240 translucent, 120 additive), 600 shadow draws
  and 120 presentation draws. Material records and pass order remain fixed;
  this is not yet authored material adoption or a general render graph.
- Graphics pipelines choose DISABLED, STRAIGHT_ALPHA or ADDITIVE blending
  explicitly instead of a boolean. Additive draws contribute source RGB
  weighted by source alpha, preserve destination alpha, and do not write
  depth in the CYMT V2 material bridge's pipeline. The bridge now adopts
  featureless ADDITIVE materials. Backend/public renderer contracts are
  versions 26/21. Frontend draw tests pass 438 assertions, material bridge
  tests 571, native OpenGL smoke 1026 including additive color/alpha/depth
  pixels, and the graybox sample completes 120 hidden frames. The sample
  has no authored additive object or dedicated additive queue yet; callers
  schedule these draws after opaque geometry.
- The graybox camera pass uses a per-object inverse-transpose normal matrix
  for nonuniform scale and shear. The sample packs three padded std140 columns
  once per object into a shared 144-byte camera/shadow record and rejects
  singular or nonfinite transforms before staging. A visible cube uses scale
  and shear, with World bounds rebuilt from the same transform. The focused
  packing test passes 14 assertions in two cases; both shaders cook without
  diagnostics, and 120 hidden frames retain 600 shadow, 720 scene and 120
  presentation draws. Mirrored transforms need a matching front-face policy.
- The graybox renderer demonstrates alpha cutout in camera and fixed D24
  shadow passes. One cube's 8x8 alpha image and 0.5 cutoff use a shared
  96-byte object uniform record; both fragment shaders discard below-cutoff
  texels before depth writes. Other sample surfaces retain their appearance.
  The CYMT V2 bridge accepts featureless MASK, preserves its 0..1 cutoff and
  creates an opaque depth-writing pipeline; callers supply matching color and
  shadow shader discard logic. Both shaders cook without diagnostics, the
  bridge tests pass 534 assertions, native OpenGL smoke passes 1003 assertions
  including color/depth/shadow pixels, and 120 hidden frames retain 600 shadow,
  720 scene (240 translucent) and 120 presentation draws. The sample still
  uses fixed material records and a temporary CPU alpha image; authored MASK
  loading and anti-aliased cutout are not implemented.
- A CPU-only scene pass classifier prepares caller-owned shadow, opaque-camera
  and blend-camera index lists. Alpha class and shadow policy are explicit;
  hidden casters still enter the shadow pass. BLEND sorts far-to-near by
  positive camera distance with input-order ties. Classes, distances,
  capacities and used buffer overlap are checked before any output changes;
  the helper makes no allocation or GPU call. The graybox sample uses it with
  its existing queues. Classifier tests pass 368 assertions, draw-queue and
  native OpenGL smoke CTests pass, and 120 hidden frames retain 600 shadow,
  720 scene (240 translucent) and 120 presentation draws. This does not load
  authored scenes or provide a general pass graph.
- The cooked material bridge adopts CYMT V2 surface BLEND as well as OPAQUE.
  BLEND makes a depth-tested, straight-alpha pipeline with depth writes off and
  preserves the cooked mode for caller-side draw ordering. At this stage, MASK
  and ADDITIVE rejected before GPU creation. BLEND shaders must emit straight
  alpha;
  callers order transparent draws after opaque ones. Material-bridge tests pass
  418 assertions across four cases, and the rebuilt fixed-material graybox
  sample completes 120 hidden frames.
- The OpenGL 4.1 graybox sample draws two translucent panels after opaque
  geometry and before HDR tone mapping, with tint alpha, depth-tested blending,
  disabled depth writes, and a fixed-capacity camera-space sorted queue. They
  do not cast in the shadow pass. The updated shader cooks with no diagnostics;
  the compact sample builds and completes 120 hidden frames with 720 scene
  draws (240 translucent), 600 shadow draws and 120 presentation draws. A
  native RGBA16F-to-RGBA8 pixel oracle verifies compositing order and opaque
  depth occlusion and unchanged depth after translucent draws; the focused
  smoke case passes 915 assertions. Sorting is
  sample-owned per object; intersecting translucent geometry remains
  unsupported. The sample does not load cooked transparent materials.
- The graybox sample now shades into a drawable-sized linear RGBA16F target
  after its fixed D24 shadow pass, then presents through an indexed fullscreen
  triangle with fixed Reinhard tone mapping and piecewise linear-to-sRGB
  encoding. A brighter sample light demonstrates values above 1.0. Physical
  resize recreates the target between frames, and partial creation is cleaned
  up. The shader cooks without diagnostics; compact sample and native smoke
  targets build, the smoke CTest passes, and 120 hidden frames complete with
  600 shadow, 480 scene and 120 presentation draws. Interactive appearance
  and resize lack automated pixel inspection; exposure controls and a general
  pass scheduler remain future work.
- Linear RGBA16F textures can serve as GPU-only offscreen color attachments
  when float render targets are supported. OpenGL 4.1 allocates GL_RGBA16F,
  and later passes may sample the completed target. R_ReadTargetRGBA8 rejects
  HDR targets without changing caller bytes instead of silently clipping;
  public/backend versions are 20/25. Four focused renderer CTests pass,
  including a native two-pass pixel check that preserves 4.0 until an explicit
  tone-map shader writes offscreen RGBA8. The cube sample rebuilds and renders
  120 hidden frames but does not use HDR yet. Float uploads/readback, cooked
  HDR assets, exposure and presentation tone mapping remain future work.
- Graphics pipelines have disabled-by-default slope and constant depth bias
  for filled triangles. OpenGL 4.1 applies offset per draw, clears it for
  ordinary draws and restores hosted offset factors and enable bits. The
  graybox shadow pass uses caster bias and a smaller shader comparison bias.
  Invalid non-finite and line/wireframe uses are rejected; public/backend API
  versions are 19/24. Compact targets build, four focused tests and the
  120-frame hidden shadow sample pass. Visual tuning across scenes and GPUs
  remains future work.
- The OpenGL 4.1 graybox sample renders a fixed directional shadow: all five
  World objects draw into a 1024x1024 D24 depth target before the four camera-
  visible draws sample it with a LESS_EQUAL comparison sampler. Two pipelines
  and queues share one pre-frame object batch. Both shaders validate and cook;
  the compact build and hidden 120-frame run pass with 600 caster and 480
  visible draws. A focused native pixel test checks a darkened receiver and
  a lit neighbor. Authored lights, robust bias/filtering, cascades, and a
  general pass scheduler remain future work.
- R_ReadTargetRGBA8 synchronously copies a validated offscreen RGBA8 rectangle
  into caller-owned pitched bytes after its target pass. The OpenGL 4.1 path
  restores read-framebuffer and pixel-pack state. Four focused renderer CTests
  pass, including fake-backend validation and native pixels/row order/padding
  and host-state restoration. Public/backend API versions are 18/23. Present
  capture, multisample resolve, asynchronous transfer and injected native GL
  failure validation remain future work.
- The graybox sample supplies ambient RGB and one directional light through
  its 176-byte per-view uniform block instead of hardcoding shader constants.
  The initial values preserve the prior shading. Offline shader validation,
  the compact build and a hidden 120-frame OpenGL run (480 draws) pass. This
  does not add authored World lights, shadows or a general lighting pass.
- The OpenGL 4.1 graybox sample VFS-reads and adopts a cooked floor checker,
  resolves visible World materials to it or a white cube texture, and samples
  the declared texture slot in its shader. The procedural grid is removed.
  The compact build, cooked assets, native texture smoke, and hidden 120-frame
  run pass at 480 draws. This is sample-owned material resolution, not general
  cooked-material or scene loading; appearance has not yet been inspected.
- The graybox renderer sample has interactive fly navigation: right mouse
  captures relative look, WASD and Space/C move, and Shift speeds movement.
  View and World culling share one pose; release, focus loss, minimize, quit,
  and event overflow clear input and restore the pointer. Pure camera tests,
  the compact build, three focused tests and the hidden 120-frame OpenGL run
  pass with 480 draws. Visible mouse interaction has not yet been manually
  exercised; finite runs retain the fixed camera.
- The OpenGL 4.1 graybox sample resolves two static mesh bundles through
  bounded host-owned logical slots: four World cubes share one mesh and a floor
  uses its own quad, bounds and tint. It checks visible mesh/material slots and
  live bundles before queuing draws. The compact target, five focused tests and
