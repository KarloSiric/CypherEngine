CypherEngine Changelog
======================

All notable changes to CypherEngine and the REAP game/runtime direction are tracked here.

[Unreleased] - 2026-10-04
-------------------------

Added - Mason map authoring
- Live block/transform dimensions, readable RGB labels, surface grids, separate
  move/resize handles and world-unit grid snapping. Multi-object resizing can
  extend each root equally or scale the combined bounds.
- Authored brush Push/Pull, brush-to-mesh conversion, mesh-face Extrude/Inset/
  Quad Slice, Quad creation and portable Copy/Cut/Paste/Paste In Place, using
  prepared document publication with undo/redo, attributes and persistence.
- Persistent authored mesh edge picks in 2D/3D, modifier selection and library
  Select Loop/Select Ring. Camera picks check physical occlusion independently
  of category filtering.
- Authored mesh vertex picks in every pane, Shift-add/Ctrl-or-Command-toggle,
  component-preserving inspector double-click and compact point cues. Neutral
  candidates appear in 2D and shaded camera previews; camera wireframe shows
  hovered/selected points only. Selection does not create an undo step.
- Mode-specific Tool Properties. Planned operations remain explicitly disabled.
- Editable contextual shortcut profiles with create/duplicate/import/export;
  settings import/export, theme/camera/viewport controls, palette icons and
  supplied Mason branding.
- Central content library, authored entity keys, configurable viewport content
  and collapsed console in the right inspector dock. Keys do not execute
  missing gameplay systems.
- Remappable camera flight-speed Increase/Decrease/Reset commands, viewport-only
  speed keys and brief feedback through the existing camera setting. Held
  fast/slow keys stay temporary. Camera properties expose speed, Go To and
  framing controls; Home frames the map from a geometric viewport.

Changed
- In 3D, plus/minus and keypad equivalents adjust camera speed; brackets keep
  grid controls. Plus/minus retain grid behavior in 2D.
- Escape cancels a gesture, leaves an idle tool for Navigation, then clears
  retained selection. Text fields/dialogs retain native behavior.
- Visible geometric-edge tolerance improves grazing-angle whole-object picks;
  component modes never substitute parent edits.
- Local validation uses one compact Mason build and existing system packages.

Fixed
- Separated 2D resize squares from move-arrow pickups by 24 logical pixels,
  including small selections and configured gizmo sizes. Draw/hover/press use
  one layout; world anchors, snapping, captured offsets and undo are retained.
- Shift-modified movement retains camera input during a camera gesture or held
  flight direction, preventing overlapping tool selection. Idle Navigation
  still accepts explicit tool chords; effective remaps and speed/framing/document
  shortcuts retain their contexts.
- Unbound command-modifier release refreshes already-held camera movement without
  another direction press; focus loss/stale repeats cannot recreate a held key.
- Selection/document/history preservation on allocation/invalid-preview failure
  and stale component pruning after visibility/topology/document changes.
- Suppressed parent mesh status dimensions in Vertex/Edge modes and blocked
  owner-entity metadata edits through a Vertex selection.
- Explicit GCC 13 aggregate resets and canonical LF map checkout on Windows.

Validation and remaining work
- Published edge checkpoint: five local suites, 200136 assertions / 808 cases;
  GitHub Actions run 37197840651 passed all 15 jobs including Mason.
- Following vertex checkpoint: five local suites, 201362 assertions / 825 cases;
  combined vertex/edge checks passed at 2x scaling and Mason captures inspected.
  GitHub Actions run 37201143691 passed all 15 jobs for the published commit.
- Camera speed/navigation: five local suites, 202343 assertions / 839 cases;
  camera subset 812 / 13 at 2x scaling; Mason captures inspected.
  GitHub Actions run 37205149950 passed all 15 jobs for the published commit.
- Shift-flight routing: five local suites, 203027 assertions / 846 cases;
  focused camera routing/modifier/remap/focus/speed checks 1493 / 23 at 2x
  scaling. Negative control detects the old command-modifier release stall.
  GitHub Actions run 37209953884 passed all 15 jobs for the published commit.
- 2D handle separation: five local suites, 214300 assertions / 847 cases;
  focused rendered move/resize checks 15623 / 5 at 2x scaling; actual Mason
  move/resize regression also passes at 2x. Tiny and boundary-at-move-tip
  workspace captures were inspected.
- Component edit adapters, face UV edits, full Hammer shortcut parity and
  renderer/ECS/audio/physics/gameplay integration remain unfinished. Full Mason
  user documentation comes later; research notes retain implementation evidence.

[Unreleased] - 2026-09-18
-------------------------

Added
- Added the accepted CYKV 2 Tier1 language path with immutable typed #define
  values, declaration-before-use references, nested namespaced member access,
  exact-case symbols, deep-copy expansion, stable errors, and bounded resource
  accounting while retaining CYKV 1 for existing formats.
- Added callback-driven, transactional #include and #base source resolution with
  parent-relative VFS requests, canonical identity, deduplication, cycles,
  dependency reporting, source-aware diagnostics, exact-schema base merging,
  matching loader release, and explicit graph/path/data limits.
- Added hard resolver ceilings for dependency depth, unique sources, and edges;
  overflow-scale options now fail before allocation or recursive traversal.
- Made authored CYKV/JSON key identity exact-case independently of a destination
  document's optional case-insensitive lookup behavior.
- Added resolved CYKV 2 writing and canonical semantic hashing plus focused
  parser/resolver tests and Release benchmarks for typed expansion and an
  in-memory dependency graph.
- Added the normative CYKV 2 specification, the generic .cydf Cypher Data File
  profile, and ADR 0007 for TileEditor/Mason document identity.

Changed
- Assigned .cymap and cypher.map V1-V3 to the deliberately small TileEditor grid
  document. A future .cymap_c now requires a real tile-runtime consumer.
- Assigned Mason professional scene/world authoring to .cyscene and planned
  cypher.scene, CypherSceneCompiler, .cyscene_c, and CypherWorld identities.
- Replaced the unimplemented .cydata proposal with .cydf for exact-schema generic
  data. CYDF reuses CYKV and does not define a second parser or universal cooked
  binary.
- Kept token macros, expressions, conditionals, environment lookups, non-finite
  literals, provenance, manifests, Tier2 adoption, and self-contained CYKV 2
  binary packing outside the implemented deterministic subset.
- Updated the reference manual, format catalog, toolchain/editor studies, module
  maps, and tool documentation to use the same ownership and status language.

[Unreleased] - 2026-09-17
-------------------------

Added
- Added the first CypherEngine Reference Manual covering architecture, ownership,
  build/VFS behavior, format versions and fields, limits, compilers, runtime
  support, diagnostics, determinism, security, migration, checklists, and glossary.
- Expanded the manual to edition 0.2 with exact source-field types, required
  state, defaults, values, ranges, versions, and cross-field rules plus exact
  binary headers, chunks, records, enums, flags, hashes, ordering, alignment,
  limits, examples, and current compiler/runtime boundaries.
- Added full contracts for CYKV text/tree packs, schemas, project/settings/config,
  CYRS, shader, texture, material, map, input-proposal, and .cypak data. Reserved
  format names now explicitly carry no frozen fields or compatibility promise.
- Recorded known implementation/specification differences for CYKV, binary pack
  identity, the two config grammars, gated source capabilities, and cooked
  render data that the current runtime does not yet consume.
- Added a researched CYKV 2 proposal for bounded includes, base composition,
  typed constants, explicit build conditionals, stronger numeric intent,
  schema-gated NaN/infinity, provenance, hashing, and binary identity while
  keeping CYKV 1 frozen.
- Added the proposed .cyinput -> .cyinput_c/CYIN and writable .cybindings family
  for typed actions, contexts, keyboard/mouse/gamepad schemes, conflicts,
  accessibility, user overrides, focus recovery, and deterministic runtime data.
- Expanded the format catalog with missing gameplay-data, localization, caption,
  animation-graph, audio, post-processing, replay, save, mod, plug-in, and
  tool-local families, and corrected the cypak V10 reproducibility claim.
- Added CYKV V2 source schemas and typed decoders for shader, texture, and
  material recipes while retaining exact V1 dispatch.
- Added semantic canonical CYKV hashing so comments, whitespace, member order,
  and equivalent number spelling do not invalidate cooker caches.
- Added CYSH V3 logical reflection, stable binding IDs, stage/type metadata,
  deterministic constant packing, canonical interface hashes, and physical GLSL
  resource verification through glslang SPIR-V and SPIRV-Cross.
- Added CYTX V2 texture semantics, multidimensional subresource metadata,
  independent payload hashes, target/residency data, exact lookup, and explicit
  V1 read compatibility.
- Added CYMT V2 bounded inheritance, cycle detection, null removals, partial
  overrides, render state, UV transforms, typed values, packed constants,
  interface identity, and strict shader/texture cross-validation.
- Added deterministic compiler identities covering formats, target/profile,
  dependencies, glslang ABI, SPIRV-Cross, image libraries, and vcpkg baseline.
- Added generation-checked runtime shader programs created from validated cooked
  CYSH views, with native OpenGL compile/link ownership and rollback.
- Added immutable graphics pipelines, shader retention, reflected uniform-block
  checks, optional sampler2D declarations, and fixed depth/cull/blend state.
- Added immediate validated indexed triangle drawing and immutable RGBA8 2D
  sampled textures with sRGB/linear storage, mip generation, repeat/clamp
  addressing, and generation-safe lifetime.
- Added the public-only rotating cube example and finite hidden-frame renderer
  smoke mode.
- Added a live tile-map preview that loads authored CYKV maps, generates blockout
  boxes, uses cooked materials/textures, and reloads changed dependencies while
  preserving the last valid state.
- Added R_InitHostSurface for borrowing an editor-owned OpenGL context,
  procedure resolver, framebuffer preparation, and presentation policy.
- Added CypherTileMapCore with transactional documents, validation, grouped
  edits, undo/redo, dirty revisions, deterministic persistence, and generated
  floor/wall/door/cliff/stair geometry.
- Added operational cypher.map V1-V3 source formats. V1 stores sparse cells and
  markers, V2 adds cardinal stairs, and V3 adds stable material-slot to .cymat
  bindings. The writer emits V3 and reads all generations.
- Added the Qt 6 CypherTileEditor with Top, Front, Side, and embedded 3D views;
  adaptive grids and rulers; fly/orbit camera; selection, paint, erase, fill,
  rectangle, line, spawn, door, eyedropper, room/piece stamps, and construction
  layers.
- Added exact sparse multiselection, move/copy/rotate/elevate/delete/bulk
  property operations, map-property editing, cross-view synchronization, and
  transactional collision/capacity/allocation failure handling.
- Added project material discovery/cooking/binding, cooked base-color previews,
  shared bounded texture caches, textured orthographic/3D display, diagnostic
  fallback, and live dependency reload.
- Added Tile Editor docks, object filtering, command console, asynchronous local
  shell, configurable workspace/camera/canvas/map defaults, custom shortcuts,
  import/export profiles, eleven themes, offline icons, and license records.
- Added renderer, format/compiler, runtime subsystem, and Tile Editor tests and
  benchmarks for normal behavior, compatibility, hostile input, determinism,
  rollback, ownership, concurrency, live graphics, and allocation failure.
- Added the complete sectioned Host startup manifest for product/build, System,
  process, seven memory arenas, FileSystem, Command, CVar, Config, Log, runtime
  policy, SDL/window/display, I/O, timings, and READY state.
- Added renderer first-draw, hosted-surface, non-renderer validation, execution
  plan, Tile Editor research, and expanded proprietary-format documentation.
- Added authored cube/tile shaders, development textures/materials, V1-V3 map
  examples, and automatic asset cooking for example/editor targets.

Changed
- Advanced current cooked render identities from CYSH/CYTX/CYMT 2/1/1 to
  3/2/2 while preserving explicit old-version readers.
- Changed texture mip generation to filter sRGB in linear space, handle straight
  alpha through premultiplied color, renormalize normal maps, and weight odd
  dimensions by exact texel area.
- Replaced the previous ad-hoc renderer route with explicit frontend/backend,
  shader, pipeline, texture, draw, standalone-surface, and hosted-surface
  contracts.
- Updated current status from the pre-shader renderer audit to the completed
  standalone first-draw/textured-blockout state; real Host and World integration
  remain the next game-facing boundary.
- Updated the format catalog to distinguish implemented Tile Editor .cymap V1-V3
  source from the planned .cymap_c runtime world.
- Added generated CYTX, CYMT, map, and mesh cooked outputs to source-control
  ignore rules.
- Reformatted startup INFO output into aligned sections and a READY block.
  Routine INFO lines omit repetitive prefixes; warnings/errors stay explicit and
  file sinks retain detailed records.
- Serialized Log state/configuration/sink access, changed Log_GetConfig to return
  a snapshot, and made sink replacement transactional.
- Split System platform services by target, consolidated platform queries, and
  standardized runtime subsystem prefixes.

Fixed
- Fixed CYRS alias/range handling and hostile shader binding counts before output
  publication or caller-memory traversal.
- Fixed renderer shader, pipeline, draw, and texture failures so native objects
  and retained references roll back before public handle publication.
- Fixed macOS available-memory accounting, arena clear-before-decommit, stale
  diagnostics, trace indexing, scratch errors, and allocator-wrapper races.
- Fixed async FileSystem cancellation/borrow lifetime, shutdown admission, and
  live native/package handle reopen preservation.
- Hardened Pak bounds, paths, compression consistency, truncation, hashes,
  temporary publication, replacement failure, and reader/writer ownership.
- Fixed Command/Config/CVar truncation, recursion, NUL/trailing input, aliasing,
  full-token numeric parsing, and default-value modified-state restoration.
- Fixed Log timestamps, truncation reporting, configuration races, failed sink
  replacement, and premature file truncation.
- Fixed Tile Editor invalid edit, allocation failure, interrupted gesture, map
  decode, material reload, and preview failure paths to preserve prior state.

Verified
- Reconfigured and rebuilt the complete tile-editor-debug graph, then passed all
  272 registered CTest entries in 25.45 seconds, including native OpenGL smoke,
  Tile Editor workspace, map/material preview, render-asset compiler, and
  ResourceCompiler process/corpus coverage.
- Built the six changed Release benchmark targets and smoke-ran all 44 cases
  across CYSH, CYTX, CYMT, canonical CYKV hashing, Memory, and Resource runtime.
  This verifies benchmark execution and is not a comparative performance result.
- Verified 232 selected non-renderer tests in Debug and ASan/UBSan plus the
  allocator-wrapper, Log, and FileSystem suites under ThreadSanitizer.
- Verified eight runtime pool cases and 58,552 assertions in Debug and
  ASan/UBSan; ran four Release pool workloads for five repetitions.
- Ran 33 Release non-renderer workloads across five executables for five
  repetitions without reported workload errors.
- Added focused format/compiler, renderer ownership/native smoke, hosted-context,
  texture sampling, map serialization, editor interaction, and rollback evidence.
- The authoritative commands, counts, timing context, and limitations live in
  CHANGELOG.md and the linked validation documents.

Known limitations
- The production CypherEngine Host does not yet own the working renderer draw
  path or an executable World loop.
- Renderer native work targets desktop OpenGL 4.1, one singleton surface,
  triangle lists, one uniform block, and one optional sampler2D.
- Shader variants, independent samplers, compressed/advanced texture cooking,
  generalized material binding, .cysurface, and hot reload remain gated.
- .cymap is an editor source format; .cymap_c, runtime World loading, general
  meshes/entities, visibility, navigation, physics, and world streaming remain
  future work.
- Current checked-in render recipes use source schema V1; V2 end-to-end behavior
  is principally covered by focused compiler fixtures.

[0.1.0] - 2026-07-04
--------------------

Added
- Added the CypherCommon Tier0 monotonic timer backend with native platform timing for Windows, Linux, and macOS.
- Added Tier0 timer tests covering initialization, frequency-based conversion, monotonic tick ordering, sleep-observed elapsed time, and stopwatch-style timer helpers.
- Added the Tier0 timer benchmark target for measuring timer tick reads and conversion overhead.
- Added Tier0 thread and system information tests to strengthen the Common foundation before higher-level runtime work.

Changed
- Replaced the earlier inline nanosecond-only timer helpers with an explicit Timer_Init, Timer_NowTicks, Timer_GetFrequency, elapsed conversion, and cy_timer_t stopwatch API.
- Renamed the public stopwatch struct from timer_t to cy_timer_t to avoid collision with POSIX timer_t on Ubuntu/Linux builds.

Fixed
- Fixed Ubuntu CI build failures caused by ambiguous timer_t resolution between CypherCommon and the POSIX system type.

Verified
- Verified local CTest coverage with all registered tests passing.
- Verified the Tier0 timer benchmark builds and runs locally.
