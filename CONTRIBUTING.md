# Contributing

CypherEngine is a proprietary project owned by Karlo Siric.

Public contributions are not accepted unless Karlo Siric explicitly requests or
approves them first. This keeps the engine legally clean while it is being built
as a long-term learning and production project.

## Contribution Rules

- Do not submit copied code from commercial engines, leaked source drops, SDKs,
  tutorials, books, websites, or other repositories unless the license is
  reviewed and explicitly approved.
- Do not submit GPL, AGPL, or similarly restrictive/copyleft code unless the
  project owner explicitly approves that dependency and its use.
- Do not remove ownership notices, file headers, license notices, or authorship
  history.
- Keep patches small, focused, and tied to one subsystem.
- Follow the existing C++20, C-style runtime, data-oriented coding direction.
- Add tests and benchmarks when touching low-level or performance-sensitive
  runtime code.
- Preserve third-party notices and licenses for any approved external library.

## Contribution Rights

By submitting a contribution, you confirm that you have the legal right to submit
it and that the contribution does not contain restricted third-party material.

Unless a separate written contributor agreement says otherwise, any accepted
contribution may be used, modified, reproduced, distributed, sublicensed,
relicensed, and incorporated into CypherEngine by Karlo Siric without payment,
restriction, or ongoing obligation.

## Engine Reference Policy

CypherEngine studies public engine architecture and engineering ideas from
projects such as idTech, GoldSrc/Source, and early CryEngine-era engines.

Reference study is allowed. Copying protected implementation code is not.
