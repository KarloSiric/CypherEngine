# Tabler Icons

These 33 outline SVGs are from [Tabler Icons](https://github.com/tabler/tabler-icons), pinned to commit `55f87a73f45cf1d9eaf16d7da705065483a9e4f9`.

Source files: `icons/outline/<name>.svg`. Copyright Paweł Kuna. Distributed under the MIT license; the exact upstream license is included in `LICENSE` and bundled in the Qt resources.

The original SVG paths are preserved. The icon factory replaces `currentColor` in memory to provide normal, active, selected, and disabled states, and renders at standard and Retina densities. No downloads occur when the editor runs.
