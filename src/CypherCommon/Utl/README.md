# Utl

`Utl` is the custom utility family, similar in spirit to Source `CUtl*`.

Expected files include `CyUtlVector`, `CyUtlMemory`, `CyUtlBuffer`,
`CyUtlString`, `CyUtlHashMap`, `CyUtlQueue`, `CyUtlRingBuffer`,
`CyUtlHandleTable`, and related containers.
