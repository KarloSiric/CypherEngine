# Tabler Icons

These 33 outline SVGs are from [Tabler Icons](https://github.com/tabler/tabler-icons),
pinned to commit `55f87a73f45cf1d9eaf16d7da705065483a9e4f9`. They were copied
unchanged from `src/CypherTools/CypherTileEditor/Resources/Icons/tabler/`, which
records the same provenance.

Copyright Paweł Kuna. Distributed under the MIT license; the upstream license is
in `LICENSE` and bundled in the Qt resources.

The SVG paths are preserved. `EditorStyle_Icon` replaces `currentColor` in
memory to tint each icon from the active theme. No downloads occur when the
editor runs.
